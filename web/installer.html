Firmware

Connect the FM-1 by USB, directly to the computer. (Works in Chrome or Edge.)

Do not unplug the USB cable while writing.

This is custom firmware: you use it at your own risk; there is no warranty. If an install fails and the FM-1 no longer starts, recovering it needs extra hardware: FM-1-transporter.

Return to official V15

Use the official V15 included here, or select an unmodified FM-1.fwsc from M-VAVE. Either is checked in this browser; nothing is sent to a server. What this firmware stored on the FM-1 is not backed up.
